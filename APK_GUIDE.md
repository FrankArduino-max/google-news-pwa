# 📱 Google News PWA - APK Android

## 📥 Download APK

L'APK compilato è disponibile in questa repository!

### File Disponibili:
- **google-news-pwa.apk** - App Android completa (Debug)
- **Dimensione**: ~50 MB (Debug) / ~30 MB (Release)
- **Min SDK**: API 21 (Android 5.0+)
- **Target SDK**: API 33 (Android 13)

## 🚀 Come Installare

### Metodo 1: Scarica da GitHub

1. **Vai al file**: `google-news-pwa.apk`
2. **Clicca Download** (o "Raw" per scaricare direttamente)
3. **Su Android**: Apri File Manager → Download
4. **Tocca** il file per installare
5. **Consenti** i permessi e conferma

### Metodo 2: Usa ADB (USB)

```bash
# Collegare il telefono
adb devices

# Installare l'APK
adb install google-news-pwa.apk

# Output:
# Success
```

### Metodo 3: QR Code (Futuro)

```
Sarà disponibile un QR code per scaricare direttamente dal telefono
```

## ✅ Dopo l'Installazione

1. **Cerca "Google News"** nella home screen
2. **Apri l'app**
3. **Naviga tra le categorie**:
   - 📰 Top News
   - 💻 Tecnologia
   - 💼 Business
   - ⚕️ Salute
   - 🔬 Scienza
4. **Clicca su una notizia** → Si apre automaticamente in **Brave Browser**
5. **Funziona anche offline!** 📴

## 🐛 Troubleshooting

### L'APK non si installa
- ✅ Controlla spazio disponibile (almeno 100 MB)
- ✅ Disinstalla versioni precedenti
- ✅ Riavvia il telefono
- ✅ Abilita fonti sconosciute

### L'app crasha
- ✅ Cancella cache: Impostazioni → App → Google News → Cancella cache
- ✅ Disinstalla e reinstalla
- ✅ Aggiorna il sistema Android

### Brave Browser non si apre
- ✅ Installa Brave Browser dal Play Store
- ✅ Controlla che sia impostato come app predefinita
- ✅ Riavvia l'app Google News

### Offline non funziona
- ✅ Disattiva wifi/dati
- ✅ Apri l'app
- ✅ Dovrebbe mostrare le notizie salvate
