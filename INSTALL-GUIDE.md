# 📱 Come Scaricare e Installare gli APK

## 🎭 Joke Generator APK

### Download Diretto (Telefono):

```
https://github.com/FrankArduino-max/google-news-pwa/releases/download/v1.0/joke-generator-v1.0-debug.apk
```

**Oppure:**
1. Vai a: Releases del repository
2. Clicca su **v1.0**
3. Scarica: **joke-generator-v1.0-debug.apk**

### Installazione:

1. **Scarica** l'APK sul telefono
2. Apri **File Manager** → **Download**
3. Tocca il file **joke-generator-v1.0-debug.apk**
4. Se chiede: **"Installa da fonti sconosciute"** → Abilita
5. Tocca **"Installa"**
6. Attendi completamento
7. **Apri l'app** 🎉

## ⚠️ Se Dice "App da fonte sconosciuta"

1. **Impostazioni** → **Sicurezza** (o Privacy)
2. Scorri e trova **"Installa da fonti sconosciute"** oppure **"App sconosciute"**
3. **Attiva il toggle** per il browser (Chrome, Brave, etc.)
4. **Torna indietro**
5. **Riprova a installare** l'APK

## 🆘 Troubleshooting

### "Non riesco a scaricare"
✅ Prova con **Brave Browser** o **Chrome**
✅ Attendi qualche secondo
✅ Controlla lo spazio disponibile (almeno 100 MB)

### "L'app non si installa"
✅ Abilita "Fonti sconosciute" (vedi sopra)
✅ Disinstalla versioni precedenti
✅ Riavvia il telefono
✅ Prova di nuovo

### "L'app crasha"
✅ Cancella cache: Impostazioni → App → [App] → Cancella cache
✅ Disinstalla e reinstalla
✅ Aggiorna Android del telefono

### "Offline non funziona"
✅ Disattiva wifi/dati
✅ Apri l'app
✅ Dovrebbe mostrare i contenuti salvati
